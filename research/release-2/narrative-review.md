# Release 2 narrative review

The existing twenty topics retain their original reference fixtures. The four new
lifecycle topics use independent, explicitly editable fixtures. A saved run opens
its original documentation; no current text is substituted as original evidence.

Reviewed integration changes:

- Configuration and uncertainty: the optional block is absent from legacy serialised
  configurations. Fifty-four lifecycle leaves are registered. New execution variations
  are disclosed scenarios only; hidden values with no observation contract are rejected.
  Adding a group does not calibrate existing chemistry, storage, weather or sensors.
- Solar and cleaning: the additional availability/irreversible condition multiplier
  enters before converter loss and clipping. Existing section cleaning still changes
  its optical surface, not irreversible ageing. The solar inspector names this extra
  loss and the original calculation retains its operands. Plant curtailment is later.
- Electrical dispatch: current accepted capacity bounds battery power, electrolysis
  and reactor heating/production. Greedy and both MPC objectives use the same bounds.
  Stored battery inventory remains recorded while unavailable. Cooling is retained.
- Electrolysis: the actual specific energy changes with private operating exposure;
  planning uses the latest eligible condition estimate. The recorded component input
  contains the actual parameter and remains retrospective. The DOE continuous-operation
  status is not a dynamic whole-system calibration or a universal lifetime law.
- Economics: construction capital replaces the modelled share of the installation
  allowance. Replacement consumption shares the existing wear/calendar pool. Purchases
  and opening stock are cash, not instant consumption. Construction is excluded from
  decision economics. Chronological lifecycle cash projections cannot repeat a short
  year as a lifetime. Service invoices are grouped by actual year for these cases.
- Services and families: generic family labels cannot grant unsupported mechanisms.
  Existing optical cleaning, prepared contacts, bounded reset and human replacement
  remain scoped. Construction is declared assisted work, not invented machine throughput.
- Observation/recovery: a queued replacement rechecks its reference at actual start;
  a procedure requires a subsequent eligible reading before confirmation. Current
  support outages are reported, without their future end time. No unrelated injected
  fault is repaired by replacing an ageing asset.
- Reproduction: existing source editions, archived reports and saved calculations
  remain unchanged. Preservation repetitions refer to their original source; Release-2
  experiments receive new identities. No numerical check establishes field validation.

Evidence gaps remain the actual condition measurement chain, equipment-specific
rates, start/thermal damage, construction effort, procedure compatibility and failure,
spare logistics and prices. Assumption ranges are stress scenarios, not confidence
intervals. These gaps remain visible in Model and the assumption catalogue.

The final integration also conservatively excludes project and field work on the
same target. Accepted field missions hold that target through return. The project
executive records the current occupied set, while service interfaces require current
project availability. This may delay or expire work and is explicitly not global
fleet optimisation. Existing field-only configurations gain no new restriction.
The Model transition ignores input events against an inert, superseded topic.

A week-long current-model trial caught a diagnostic audit still using fixed SEC.
Its corrected invariant uses the decision's original estimated SEC; the independent
lifecycle checker binds that estimate to the latest eligible observation. Physical
SEC is separately derived from exposure. The generic archive audit selects this
version-aware independent checker for lifecycle records. The commissioning essay
now displays beginning-of-interval package state alongside its ending state, so
acceptance and available capacity are not shifted a clock boundary in the diagram.

The annual chronology exposed repeated graph encoding and hashing of a growing
service history. The corrected checkpoint implementation retains an independent,
allowlisted transaction image after every committed hour and encodes its portable
graph at the export boundary. The Sites narrative remains accurate: inventories,
heat, beliefs, service work and economic usage cross partitions without reset.
Its review binding and resource-conversion teaching fixture were refreshed for this
source. Cancellation/failure tests exercise mutations in the uncommitted following
interval. A separate two-source experiment compares the same saved 24-hour
continuation; it is not a resumed old study or inherited qualification.
