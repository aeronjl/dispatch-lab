# Release 3 — learning and experimental policies

[Read the release report](report.html). The report separates shipped software,
named acceptance checks, unresolved external gates and subsequent algorithm work.
The scope is an experiment platform, not an exhaustive policy research programme.

- `acceptance.py`: saved, bounded workflow using the versioned Sites continuity
  fixture. Run from the repository root with the locked environment.
- `acceptance.json`: dataset/model/study identifiers, incomplete duration example,
  cancellation/resumption, numerical edition differences and portable bundle sizes.
- `qualification.json`: check outcomes and exact source identity under test.
- `source-review.md`: narrative review of the changed model/control boundaries.

Full stores, source capsules, ZIPs and screenshots remain under `build/` and are
ignored. Paths and hashes in the receipts identify those local artifacts; Git is
not their backup. Report HTML embeds its font and needs no network access.
