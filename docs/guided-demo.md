1. **See the coupled plant.** Start with the default 72-hour synthetic experiment. Play at 2×, then pause when methanation first starts. Inspect the reactor’s **Now** heat terms and **Why** temperature band. Watch the hydrogen buffer connect midday electrolysis to later methane.
2. **Understand a decision.** Switch between Greedy and MPC · methane at the same hour. Inspect the battery’s **Why** discharge window and **Next** forecast trajectory. Compare methane alongside ending energy and material inventories.
3. **Introduce uncertainty.** In setup set forecast bias to 0.35, capacity fraction to 0.5, fault start to hour 34, with persistent lifecycle (the default for new configurations). Duration only applies to explicitly transient faults. Choose a field-services preset to model repair and subsequent measured recovery. Run again. The event strip moves from observations to diagnosis to a changed capacity estimate. The injected truth is available only in the labelled retrospective panel.
4. **Distinguish a sensor fault.** Restore capacity fraction to 1 and set flow bias to 0.4. Re-run. Power and independent hydrogen mass balance can support isolating the flow channel without declaring a capacity loss. Inactive equipment has insufficient evidence.
5. **Test an alternative.** Select a battery discharge interval, choose **What if**, and prevent discharge. Compare the two predictions from exactly the same original information. Test delayed CO₂ supply from its buffer. An infeasible alternative or missing incumbent is evidence, not an output improvement.
6. **Examine economics.** Switch to MPC · economics. Toggle component costs or inspect **Costs**. Reprice a completed run, then inspect **Next** to see that its original decision costs remain frozen. Rerun to apply new dispatch incentives.
7. **Compare experiments.** Expand the evidence area. Run the seeded matrix and diagnosis-disabled ablation, then thermal sensitivities and historical windows. Export decisions and raw weather. Check unsuccessful cases, time limits, false alarms and ending inventories before drawing conclusions.

All values are illustrative. This is hourly scheduling and bounded diagnosis, not a plant controller or gas-quality certification. Methane value is an assumption; contribution is not investment return. No DePIN settlement is implemented.
