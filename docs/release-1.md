# Release 1: qualified reference autonomy

Authorised 14 September 2026. Complete this release, then report its evidence and
the remaining Releases 2 and 3. The wider fourteen-family/learning programme is
not part of this release. Existing supported service mechanisms are.

## Acceptance contract

1. Version the corrected recovery policy. Separate individual test appointments
   from immutable diagnosis/post-mission deadlines. Retain observed confirmation,
   resource-aware scheduling, bounded retries, degraded operation and escalation.
   Preserve versions 1–4, original archives and saved failures.
2. Turn saved recovery failures into identified qualification cases. Use the same
   original inputs; record changed policy/source/budget explicitly. Include failed
   remedies, sensor bias, insufficient power, normal operation and seasonal cases.
3. Publish matched three-controller reference comparisons with independently
   identified event seeds and numerical repeats. Report solver limitations,
   physical/cost balances, ending inventories and unresolved service obligations.
   Do not require MPC to win or interpret repeats as new weather observations.
4. Complete interactive Model coverage for the existing service system: cleaning,
   imperfect inspection, bounded interventions and verification, support/charging,
   finite logistics/people, service accounting and uncertainty. Connect original
   records to explanations without altering the simulation illustration.
5. Preserve a source-bound, readable release report, protocols, failed attempts,
   offline outputs and reproduction instructions. Run appropriate full regression,
   browser, documentation, independent-audit and performance checks. Record an
   agent-led comprehension walkthrough separately from participant research.

## Scope of evidence

This is a numerically qualified hourly research sandbox. Existing literature
reviews and uncertainty ranges remain applicable only within their recorded
identities and scopes. No new field observations, repair capability, logistics
quotation, thermal calibration or empirical reliability is invented.
