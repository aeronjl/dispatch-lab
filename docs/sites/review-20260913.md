# Mechanism review for the Sites increment

The existing physical kernels and their starting constants are unchanged. Reviewed
optional execution additions: continuous checkpoint boundaries, service cost-prefix
preservation, independent water-supply limits, frozen source execution and weather
publication selection. Thermal, battery, gas and stoichiometric explanations still
describe those kernels. A continuous run does not reset inventories at a partition.

The new recovery version is an explicit policy variant. Its deadline is opened from
eligible forecast information and then fixed. It neither observes private fault
truth nor infers recovery from a procedure receipt. Existing recovery and controller
passages were extended to state this boundary. Earlier policies retain their meaning.

The new Sites essay separates a toy area calculation, current resource conversion
and a fixed-production cash example. The cash example is deliberately independent
of its resource example; it does not fabricate methane from irradiance. Real Sites
cash reports use recorded production. Source review establishes applicability and
numerical mechanics only; no new field calibration or success probability is claimed.

Assumption review bindings are renewed for reviewed existing groups because shared
Config, simulation and service files changed. Their evidence status, ranges and
source limitations remain unchanged. A separate Sites implementation document and
source catalogue describe new interfaces rather than falsely extending older
parameter calibrations. New automated evidence must match its executed source.
