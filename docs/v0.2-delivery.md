# v0.2 implementation and validation

The three planned increments are implemented in a separate `methane` package while preserving v0.1 modules and archives.

| Increment | Implementation |
|---|---|
| Coupled plant and visibility | `config.py`, `physics.py`, `dispatch.py`, `costing.py`; hydrogen/CO₂ inventories, analytic reactor heat, explicit dispatch, recorded trajectories, live weather snapshots and illustrated component inspection |
| Autonomy and alternatives | `sensing.py`, `simulation.py`; observation/truth separation, bounded residual diagnosis, conservative recovery probes, economic MPC, event navigation and same-information what-ifs |
| Comparative evidence | `weather.py`, `evidence.py`; forecast vintage selection, raw cache, historical reference, batch cancellation/reuse, thermal and diagnosis ablation, versioned JSON/CSV/weather exports and guided demonstration |

`ui.py` separates simulation, replanning, repricing and batch callbacks. Browser JavaScript renders authoritative records; simulation and cost accounting stay in Python. The UI preserves Departure Mono and an amber SVG instrument view, with narrow-screen equipment navigation and reduced-motion support.

Automated checks cover analytic thermal transitions, chemistry and energy conservation, storage bounds, cold starts, forced trips, minimum-run commitments, an analytically checkable benefit from saving energy, invalid incumbents, fault classification/recovery, forecast causality, availability/DST boundaries, missing/offline weather, immutable what-ifs, single wear allocation, repricing and archive schemas. JavaScript checks cover the playback clock, causal frame selection and response identity.

Browser verification covers all policies, playback/stepping/speed, equipment inspection, recorded plans, a completed what-if callback, cost toggling, event navigation and a 390-pixel viewport. Detailed evidence reports are generated into `runs/methane-v2/batches` and remain separate from the test assertions. Planning is not required to outperform the local rule in every case; time limits and failed/incomplete experiments are retained.

Final checks: 63 Python tests and 16 JavaScript tests pass; Ruff, formatting, whitespace checks and the offline dependency-lock check pass. The 51-case evidence suite completed with 153 traces. See [findings and full local reports](evidence-summary.md). Current forecasts were fetched successfully and replayed identically from cache; historical data covers all nine agreed windows. Repricing and simulation APIs, actual what-if responses, keyboard inspection, narrow screens and stale-response rejection were exercised against the running app.
